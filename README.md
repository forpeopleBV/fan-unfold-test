# Collections 2027 splash screen

A responsive, single-screen Vite + React animation using the supplied collection artwork.

## Run locally

```bash
npm install
npm run dev
```

Press `C` to open the controls for echo count and echo delay. Press `C` or `Esc` to close them.

## Structure

- `Asset/` — original collection artwork
- `Inspiration/` — supplied motion reference
- `src/components/` — animation and controls
- `src/hooks/` — keyboard interaction
- `src/data/` — collection asset definitions
